# 薄明よみ（hakumei-yomi）

日の入り後や日の出前に、太陽の中心が地平線の下何度か（伏角）を見て、常用薄明・航海薄明・天文薄明のどれか（または太陽が出ている・薄明の外）を当てる1日5問の学習ゲーム。正解したら、その時間帯の明るさの目安も選ぶ。薄明の区切りや日の出・日の入りの決まりの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/hakumei-yomi/>

- 中身は国立天文台 暦計算室「暦Wiki 薄明」<https://eco.mtk.nao.ac.jp/koyomi/wiki/C7F6CCC0.html> と「暦象年表 用語の解説」<https://eco.mtk.nao.ac.jp/koyomi/faq/glossary.html> に書いてあることだけです。
- 問題に出る角度は練習のための例で、本物の観測の記録ではありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
